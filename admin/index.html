Admin

Hier änderst du die Inhalte deiner Website selbst. Jede Änderung wird als Commit auf GitHub gespeichert und ist etwa eine Minute später online.

So bekommst du einen Token (einmalig, 2 Minuten)
  1. Auf GitHub einen neuen Fine-grained Token anlegen.
  2. Name zum Beispiel „Website-Admin“, Ablauf: 1 Jahr.
  3. Unter Repository access „Only select repositories“ wählen und nur ericwinderlich/website auswählen.
  4. Unter Permissions bei Contents „Read and write“ einstellen. Sonst nichts.
  5. Token erzeugen, kopieren und hier einfügen. Dein Browser merkt ihn sich, auf einem neuen Gerät fügst du ihn einmal neu ein.

Der Token bleibt nur in diesem Browser gespeichert und wird nirgendwohin geschickt außer an GitHub.
